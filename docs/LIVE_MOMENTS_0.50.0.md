# MOMENTO 0.50.0 — «здесь и сейчас»

## Реализовано в исходном коде
- Удалён выбор ранее записанного видео из архива комнаты.
- Запись только через встроенную CameraX; проверка фактической длительности MP4 2000–5000 мс.
- Автоматическое сохранение после успешного завершения записи, без ручного подтверждения.
- Запись останавливается примерно через 4,7 с (с запасом на задержку финализации CameraX).
- При активной комнате запись автоматически привязывается к ней.
- Удалена ручная перестановка моментов. Порядок добавления хронологический.
- Локальная публикация пустой комнаты запрещена.
- Добавлены периодические напоминания для комнаты: выключено, 1, 3, 6 часов через WorkManager. Android может сдвигать время; это **не точные напоминания по расписанию**.
- Уведомление ведёт в MainActivity с идентификатором комнаты; после проверки авторизации открывается камера.

## Не реализовано
- Точное расписание и случайные напоминания; отдельная настройка уведомлений для подписчиков.
- Публикация открытых комнат, подписки, комментарии и серверная модерация.
- Сервер не может криптографически доказать происхождение видео из камеры: это требует дополнительного протокола подтверждения записи.
- При первом входе или истёкшей сессии переход из уведомления сначала требует авторизации.
- Android SDK/Gradle-сборка, проверка поведения CameraX на устройстве и получение APK.

## Проверки
`python scripts/test_live_moments_policy.py` — проверка инвариантов исходников, не компиляция.
`python scripts/verify_project.py` — серверные и структурные проверки.
