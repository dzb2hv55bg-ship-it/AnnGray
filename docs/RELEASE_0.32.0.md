# MOMENTO 0.32.0 — ручная загрузка из Android-архива

- Добавлена кнопка загрузки отдельного локального момента в приватный серверный архив.
- Повторные попытки используют сохранённый SQLite request ID; состояние UPLOADING / FAILED / UPLOADED_PRIVATE отображается через кнопку или сообщение.
- Ограничено создание новых локальных записей 2–5 секундами.
- Автоматическая фоновая отправка намеренно не включена.

## Ограничения и риски
- Android SDK и Gradle не доступны для проверки компиляции; Kotlin UI требует сборки на Android.
- Реальная PostgreSQL, FFprobe и авторизация провайдеров не тестировались интеграционно.
- Локальный архив пока не разделён по пользователям: перед автоматической синхронизацией необходима привязка очереди к account ID, иначе на общем устройстве возможна отправка чужого локального момента. Поэтому загрузка только ручная.
- Нужно проверить обработку завершения загрузки при истечении JWT, logout и процессе, закрытом во время запроса.
