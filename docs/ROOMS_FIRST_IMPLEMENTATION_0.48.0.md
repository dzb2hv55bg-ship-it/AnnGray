# MOMENTO 0.48.0 — первый реализованный этап rooms-first

## Реально изменено
- Нижняя навигация: Комнаты / Создать / Мои / Поиск / Профиль.
- Главный экран теперь посвящён комнатам; нет ленты постов.
- Создание локального черновика комнаты: название, описание, тип доступа, тема.
- SQLite миграция v1 → v2 без удаления существующих комнат; сохранение новых полей.
- Мои комнаты: локальный список и фильтры.
- Поиск: только по локальным комнатам данного подтверждённого аккаунта.
- Личный архив, камера, календарь, капсулы и выход из аккаунта доступны через профиль.
- Material 3 использует цвета текущей светлой/тёмной темы.
- Тест миграции SQLite, проверки исходников и серверные тесты.

## Не реализовано и не должно считаться готовым
- Публичный каталог и рекомендации, подписки, авторские профили, комментарии, реакции и уведомления.
- Привязка видео к комнате, серии, редактор порядка, публикация, просмотр мини-влога.
- Реальный сервер для публичных комнат и OAuth-ключи.
- Компиляция Kotlin и Android APK (SDK/Gradle недоступны здесь).

Все созданные комнаты остаются локальными черновиками; выбор PUBLIC не публикует данные.
Не загружайте публичные комнаты без реализации серверной авторизации, модерации и контроля доступа.

## Сборка в GitHub
Скопируйте содержимое проекта в репозиторий и запустите Actions → Android APK build → Run workflow. При успешной компиляции артефакт MOMENTO-debug-apk содержит app-debug.apk. При ошибке изучите Gradle log.
