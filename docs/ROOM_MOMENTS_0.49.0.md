# MOMENTO 0.49.0 — локальные моменты в комнатах

Реализованы: SQLite v3 (таблица room_moments), привязка существующих локальных видео к комнатам, удаление связи без удаления файла, перестановка моментов, серии «День N», просмотр локальных видео по порядку и индикатор «Момент N из M». После записи видео из комнаты оно автоматически добавляется в неё.

**Ограничения:** загрузка внешних файлов, монтаж, публичная публикация, серверная выдача комнат, подписки, реакции, комментарии, уведомления и серверный поиск ещё не реализованы. Не выдавать локальные комнаты за опубликованные. Android SDK недоступен, компиляция не подтверждена. UI-свайпы требуют проверки на эмуляторе; VideoView может перехватывать жесты.

**Миграция:** SQLite v2 -> v3 создаёт новую таблицу без изменения существующих комнат; миграция v1 -> v3 также добавляет прежние поля комнаты.
