# MOMENTO — проверенный срез реализации

## Согласованная навигация
Камера / Комнаты / Подписки / Профиль. Создание комнаты и список своих комнат доступны с главного экрана, поиск — дополнительный экран, календарь/капсулы/архив — из профиля. Предыдущая панель из пяти пунктов была устаревшей.

## Изменено в этом срезе
- `ui/MomentoApp.kt`: четыре нижних раздела; отдельный экран подписок, новый главный экран, выбор комнаты в камере; после загрузки локальных комнат выбирается первая активная, после создания — новая комната.
- `ui/LiveHomeScreen.kt`: главный экран с приоритетом камеры, локальные комнаты и понятное пустое состояние. Публичные публикации не симулируются.
- `ui/CameraScreen.kt`: быстрый выбор комнаты на экране камеры, без импорта файлов.
- `data/RoomReminderRules.kt`: сохранён алгоритм пяти детерминированных случайных времён на аккаунт и дату.

## Реальные проверки
- `npm test` (backend): 86/86 passed.
- Отдельная компиляция `RoomReminderRules.kt` через `kotlinc` и выполнение 10 000 расписаний: passed.
- `scripts/test_rooms_schema.py`: passed.
- `scripts/test_upload_queue_migration.py`: passed.
- Проверка связей навигации на уровне исходного текста: passed, НЕ является компиляцией Android.

## Не проверено и не готово
- Android Gradle, Compose compilation, Android Lint, instrumented tests, эмулятор, APK: не выполнялись; Android SDK и wrapper JAR отсутствуют.
- Подписки: отображается явное пустое состояние, сквозная серверная функция НЕ реализована.
- Публикация открытых комнат и API-синхронизация комнат: сквозной сценарий НЕ реализован.
- Камера и последовательный просмотр: имеются исходники, работа на Android НЕ подтверждена.
- Серверный код и 86 тестов НЕ означают работающий развернутый сервис.
- Проверка происхождения видео только метаданными/токенами не обеспечивает гарантии записи камерой.
- Gradle Wrapper JAR отсутствует: workflow пытается восстановить и проверить SHA-256; URL/хэш и сборка должны быть проверены реальным запуском CI.

## GitHub
Загрузить содержимое каталога `MOMENTO-android` в корень репозитория, запустить Actions → Android APK build → Run workflow. При падении скачать `MOMENTO-gradle-failure-log` и анализировать фактический стек ошибок. Только успешный workflow может подтвердить APK в Artifacts.

## Телефон — после APK
1. Установка и первый вход; 2. создание личной комнаты; 3. выбор комнаты прямо в камере; 4. запись 2–5 секунд; 5. сохранение и просмотр; 6. прерывание/отказ в доступе к камере; 7. офлайн-запись; 8. напоминания и разрешения; 9. светлая/темная тема; 10. повторный запуск и сохранность локальных данных. Для диагностики: `adb logcat -d -v time > momento-log.txt` (перед передачей удалить токены и личные данные).
