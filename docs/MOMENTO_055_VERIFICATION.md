# MOMENTO 0.55.0

Исходная ревизия — `9abbc84527f0bcca12db16ee7447830ad495d7e3`. Android 0.55.0, build 38, package `ru.momento.app`, Android API 24 и выше.

## Изменения

- «Жизнь в секундах» в профиле. Фильтр периода, хронология личных моментов, кадр обложки, экспорт Media3, просмотр фильма, системное сохранение и отправка. Исходники берутся из каталога проверенного аккаунта.
- Комнаты события и секретные комнаты в разделе «Комнаты». Камера ставит момент в очередь с конкретным ID серверной комнаты. Сервер закрывает запись после завершения события и сохраняет историю до архивации комнаты.
- Секретные комнаты используют одноразовые приглашения. Вступление блокирует строку комнаты в транзакции, чтобы разные приглашения не могли занять одно место. Отзыв и выход также отзывают действующие ссылки.
- В событийном фильме каждый фрагмент скачивается через авторизованный API. Экран периодически перепроверяет членство. Экспорт события доступен для просмотра внутри приложения.
- Уведомления секретных комнат включаются по желанию участника и используют одну периодическую задачу на аккаунт. Пять ежедневных напоминаний о записи продолжают планироваться отдельно.
- Исправлена ошибка Kotlin в удалении старых полей настроек напоминаний. Для поддержки Android API 24–25 включён desugaring Java Time. Сетевой клиент комнат запрещает автоматические перенаправления авторизованных запросов.
- Миграции `008` и `009` применяются последовательно. Новые значения enum должны быть сохранены до применения ограничений из `009`.

## Безопасность и эксплуатация

- Завершение, удаление комнаты и снятие участника требуют права владельца. Участник может выйти сам. Архивация убирает комнату из списков и выдачи связанной истории. Личная копия момента остаётся у автора.
- Выдача серверного видео проверяет доступ к моменту, активность комнаты и блокировки на момент запроса. Уже скачанный материал нельзя дистанционно отозвать у получателя. Секретные комнаты используют серверную авторизацию.
- Открытый проект не содержит развёрнутого HTTPS API, конфигурации OTP/OAuth и доверенного процесса возрастной проверки. Серверный возрастной контроль остаётся обязательным. Обход этого контроля, в том числе через ввод возрастной группы из приложения, здесь отсутствует.
- Периодические фоновые уведомления доставляются с задержками, зависящими от Android и сети. При активном просмотре приложение опрашивает сервер каждые 15 секунд.
- Настройки кодеков, обработку длительных подборок, доступность на малых экранах и полевую производительность следует проверять с реальными видео на целевых устройствах. Локальные длительности тестов не являются метрикой производительности приложения.
- Конфигурация сборки в `BUILD_ANDROID.md`. Для офлайн-сборки передайте `-PmomentoAllowOfflinePreview=true -PmomentoRequireLiveAuth=false`. Для авторизации нужен собственный проверенный HTTPS endpoint через `-PmomentoApiBaseUrl=...` и соответствующие настройки backend.
