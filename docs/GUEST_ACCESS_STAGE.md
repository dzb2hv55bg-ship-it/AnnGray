# MOMENTO — гостевой режим (код, не подтверждённый Android-сборкой)

- Гостевой вход не создаёт аккаунт, токен или серверную сессию. Кнопка на AuthScreen.
- GuestHomeScreen доступен без API. Пустой API или сетевой сбой показывают «Публичные влоги пока недоступны».
- GET /v1/discovery/spaces и GET /v1/spaces/:id/moments для анонимного пользователя допускают только опубликованные PUBLIC комнаты. GET /v1/moments/:id/video допускает только публично привязанные видимые медиа.
- Все POST/PUT/DELETE остаются за authenticate(). Гостю предлагается вход при попытке публикации, отмена возвращает в гостевой режим.
- После входа по намерению публикации открывается создание комнаты; публикация требует последующего подтверждения. Полное возобновление ранее снятого гостевого черновика не реализовано, поскольку гостевая камера не подключена.
- Гостевой кэш видео отделён от кэша авторизованного просмотра.
- Проверки: Node.js tests 96 passed, 2 skipped. PostgreSQL не запускалась. Android unit/lint/assemble не прошли: Gradle Wrapper пытается скачать Gradle из недоступной сети. APK НЕ СОБРАН.
- Для сборки гостевого UI без API: `./gradlew assembleDebug -PmomentoAllowOfflinePreview=true -PmomentoRequireLiveAuth=false`. Это гостевая проверочная сборка без входа по OTP, не релиз. При настроенном HTTPS API используется обычная сборка.
- Для реальной проверки нужны сервер, PostgreSQL, тестовое Android-устройство и успешная Gradle-компиляция.
